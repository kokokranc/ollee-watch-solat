
# Ollee-watch-solat

## Intro
Ollee forge script to calculate daily islamic prayer times. This face for the Ollee Watch is based on Gregor's example in [Forge Emulator rep](https://github.com/olleewatch/forge_emulator/tree/main).

## Features
1. Daily prayer times (5x) + sunrise
2. Prayer time caching to reduce computation overhead
3. Automatic refresh when moving between location and timezones
4. Using Malaysia (JAKIM), North American ISNA, Umm- al-Qura and Muslim World League standard, according to location
5. +- 10 minutes accuracy

## How to use
1. Enter watchface.
2. First face is Fajr of the day or the last prayer time opened.
3. Navigate using A button (bottom right). It will cycle the prayer time as follows:
   ... -> FaJr -> sunRIse -> DHuhr -> 'ASr -> Maghrib -> ISha' -> ...
